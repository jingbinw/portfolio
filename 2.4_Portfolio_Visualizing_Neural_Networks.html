03 · Core concepts

Structure, computation, and learning

Layers

Groups of neurons arranged by processing stage. The input layer receives features, hidden layers learn patterns, and the output layer produces predictions.

Neurons

Small computational units. Each neuron combines incoming values, weights, and a bias, then applies an activation function.

Weights

Learned numbers on connections. They scale incoming signals and are adjusted during training to improve predictions.

z = w₁x₁ + w₂x₂ + … + b    →    output = activation(z)

Input values are multiplied by weights, combined with a bias, and passed through an activation function. Repeating this operation across layers enables the network to learn patterns.

Activation functions

Transform a neuron's weighted sum. Tanh was used in all five recordings. It maps values into the range −1 to +1 and introduces non-linearity.

Loss functions

Measure prediction error. Training Loss measures error on training examples; Test Loss measures performance on held-out examples.

Optimization algorithms

Use gradients from the loss to update weights and biases. The Playground's training process iteratively adjusts parameters to reduce loss.

1Prediction 2Calculate loss 3Compute gradients 4Update weights

This cycle repeats across training steps. Lower loss generally indicates a closer fit to the target labels, but Test Loss is especially useful for judging generalization.

05 · The five experiments

Configurations, observed results, and interpretation

Loss and epoch values below are transcribed from the presentation's recorded states.

01

Baseline XOR model

Starting point: one hidden layer with four neurons and the original two input features.

Dataset: XOR classification · Noise: 0 · Features: x₁, x₂ · Network: 1 × 4 neurons · Learning rate: 0.03 · Activation: Tanh

Epoch shown1,868
Training Loss0.064
Test Loss0.190

What the result suggests: The baseline model learned part of the XOR pattern, but displayed Test Loss remained relatively high. The output map still showed imperfect class separation at capture.

Key takeaway: XOR requires a non-linear decision boundary. This basic setup provides a comparison point, but had not yet reached very low Test Loss.

02

Increasing noise

The main change was increasing dataset noise from 0 to 30.

Dataset: XOR classification · Noise: 30 · Features: x₁, x₂ · Network: 1 × 4 neurons · Learning rate: 0.03 · Activation: Tanh

Epoch shown1,870
Training Loss0.075
Test Loss0.210

What the result suggests: Compared with baseline, both displayed losses were higher: Training Loss rose from 0.064 to 0.075 and Test Loss from 0.190 to 0.210. Output regions also appeared less cleanly separated.

Key takeaway: Noise can obscure the underlying pattern. In this recorded run, measured error increased.

03

Adding an input feature

The main change was enabling x₁x₂ while keeping the XOR task and one hidden layer.

Dataset: XOR classification · Noise: 0 · Features: x₁, x₂, x₁x₂ · Network: 1 × 4 neurons · Learning rate: 0.03 · Activation: Tanh

Epoch shown1,497
Training Loss0.000
Test Loss0.001

What the result suggests: Displayed loss dropped substantially compared with baseline. The output map formed a clear four-quadrant pattern, closely matching XOR labels.

Key takeaway: A useful engineered feature can make a difficult relationship easier to represent. x₁x₂ directly provides information about the interaction between the inputs.

04

Increasing network depth

The network was expanded from one hidden layer to two, with four neurons in each layer.

Dataset: XOR classification · Noise: 0 · Features: x₁, x₂, x₁x₂ · Network: 2 × 4 neurons · Learning rate: 0.03 · Activation: Tanh

Epoch shown1,149
Training Loss0.000
Test Loss0.007

What the result suggests: The two-hidden-layer model also achieved very low loss. Test Loss was 0.007, slightly higher than Experiment 3's 0.001, while Training Loss remained displayed as 0.000.

Key takeaway: More layers increase capacity but do not automatically improve test performance. The simpler feature-augmented model had lower displayed Test Loss here.

05

Switching to the Circle dataset

The dataset changed from XOR to Circle; the network retained two hidden layers with four neurons each.

Dataset: Circle classification · Noise: 0 · Features: x₁, x₂ · Network: 2 × 4 neurons · Learning rate: 0.03 · Activation: Tanh

Epoch shown1,192
Training Loss0.000
Test Loss0.007

What the result suggests: The output shows a circular decision region, with one class concentrated near the center and the other surrounding it. Both displayed losses were low.

Key takeaway: Different datasets require different decision-boundary shapes. In this recorded run, the network represented the circular pattern successfully.

07 · Reading the evidence

What the five experiments suggest

The results connect model settings to decision boundaries and generalization.

Noise matters

Experiment 2 had higher Training and Test Loss than baseline. Noise can obscure the pattern and make classification harder.

Features matter

Adding x₁x₂ in Experiment 3 coincided with a large improvement in displayed loss. Feature representation can matter as much as network size.

Depth is not always better

Experiment 4 used more layers but Test Loss (0.007) was higher than Experiment 3 (0.001). Greater complexity does not guarantee better generalization.

Decision-boundary observations

  • Baseline XOR: The output boundary was still imperfect at capture.
  • Noisy XOR: Class regions were less clean and recorded losses were higher.
  • Feature-augmented XOR: The output formed a clear four-quadrant pattern.
  • Circle: The model learned a central region surrounded by the other class.

Interpretations are limited to the settings and moments visible in the recordings. Repeated trials may produce slightly different values.

08 · Methodological limits

How to interpret the results carefully

A good experiment report distinguishes what the recording shows from what it does not show.

What the recordings directly show

  • Dataset and selected features
  • Noise slider setting
  • Hidden-layer and neuron counts
  • Epoch counter at capture
  • Training Loss and Test Loss at capture

What cannot be concluded exactly

  • Actual wall-clock training duration
  • That one run proves a universal rule
  • That lower Training Loss always means better generalization
  • Exact causality when multiple settings differ

Epoch counters and speed: Displayed counters differ (1,149–1,870), but videos may have been stopped at different times. This report gives the visible epoch values and does not claim one configuration trained faster in real time. For a strict speed comparison, run each configuration for the same number of epochs and measure elapsed time under the same conditions.

09 · Summary

Key takeaways

Visualizing a neural network makes learning easier to understand.

Structure

Layers organize processing. Neurons compute values, and weights control the strength of connections.

Learning

Tanh adds non-linearity. Loss measures error, and optimization updates the network's parameters.

Experiment insight

Useful features can improve learning. Noise can make it harder. More layers do not always improve test results.

The most important lesson: Model performance depends on the relationship between the data, its features, and the network architecture—not simply on making a network larger. A neural network is not a black box: its behavior can be explored by changing one component at a time and observing the result.

10 · Personal reflection

Learning by visualizing and experimenting

Using TensorFlow Neural Network Playground helped me understand how a neural network learns patterns from data. By changing noise, input features, hidden layers, and dataset type, I could see how the decision boundary and loss values changed.

The most surprising result was that adding the x₁x₂ feature greatly reduced the loss in the XOR experiment, while adding another hidden layer did not improve Test Loss further. This activity showed me that choosing meaningful features and matching the model to the data are important parts of machine learning.
