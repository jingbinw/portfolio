The framework

Two broad learning approaches

Supervised learning

Learns from labeled examples to predict a target value or assign a class. The framework includes Linear Regression, Logistic Regression, Decision Tree, Random Forest, SVM, KNN, and CNN.

Unsupervised learning

Finds patterns or structure in data without a target label. K-Means and PCA are core examples in this framework.

Generative model: GANs learn to create synthetic examples through adversarial training. Their training setup can vary, so a GAN is not always strictly unsupervised.

The collection

10 algorithms, explained

Each profile highlights its common learning type, application domains, a use case, and how it works.

01

Linear Regression

Supervised · Regression

Tabular Data

Real-world use: Forecasting house prices, sales, or energy demand from numeric features.

How it works: Fits a line or hyperplane that minimizes squared differences between predicted and observed numeric values.

02

Logistic Regression

Supervised · Classification

Tabular DataNLP

Real-world use: Predicting customer churn or classifying an email or review as spam or not spam.

How it works: Maps weighted input features to class probabilities, commonly using the logistic (sigmoid) function for binary classification.

03

Decision Tree

Supervised · Classification / Regression

Tabular DataComputer Vision*

Real-world use: Assessing loan risk or predicting whether a customer is likely to leave.

How it works: Splits data through feature-based questions; each branch narrows the decision until a prediction is reached.

04

Random Forest

Supervised · Ensemble

Tabular DataComputer Vision*

Real-world use: Fraud detection, credit-risk scoring, and feature-based medical risk prediction.

How it works: Trains many decision trees on varied samples and features, then combines their predictions to improve robustness and reduce overfitting.

05

Support Vector Machine (SVM)

Supervised · Classification / Regression

Tabular DataComputer VisionNLP

Real-world use: Classifying images, categorizing text, or detecting sentiment with engineered features.

How it works: Finds a decision boundary that maximizes the margin between classes; kernels can model nonlinear boundaries.

06

K-Nearest Neighbors (KNN)

Supervised · Instance-based

Tabular DataComputer Vision

Real-world use: Classifying a handwritten digit or recommending similar items or users from feature similarity.

How it works: Looks up the k most similar training examples; predicts by majority vote for classification or averages values for regression.

07

K-Means Clustering

Unsupervised · Clustering

Tabular DataComputer Vision*

Real-world use: Segmenting customers into behavior groups or grouping similar image colors and pixels.

How it works: Assigns points to k clusters around centroids, then repeatedly updates assignments and centroids to reduce within-cluster distances.

08

Principal Component Analysis (PCA)

Unsupervised · Dimensionality reduction

Tabular DataComputer VisionNLP*

Real-world use: Compressing high-dimensional sensor data or reducing image and feature dimensions before modeling.

How it works: Transforms correlated features into fewer orthogonal components that preserve as much data variance as possible.

09

Convolutional Neural Network (CNN)

Supervised (common use) · Deep learning

Computer Vision

Real-world use: Detecting production-line defects, identifying objects, or assisting medical-image classification.

How it works: Learns filters that detect local patterns such as edges and textures, building them into increasingly complex visual features.

10

Generative Adversarial Network (GAN)

Generative model · Adversarial training

Generative AIComputer Vision

Real-world use: Generating synthetic faces or product images, creating training data, or translating images.

How it works: Trains two networks together: a generator creates synthetic samples while a discriminator learns to distinguish generated samples from real ones.

About domain tags: A tag indicates a plausible application, not that an algorithm is always the best choice. The asterisk marks applications using image-derived features; CNNs are more purpose-built for raw spatial image patterns. PCA can also be applied to text features.

Where data lives

Four application domains

Tabular Data

Rows and columns: business metrics, finance, sales, risk, and customer records.

Computer Vision

Images and video: object recognition, defect detection, and medical imaging.

Natural Language Processing (NLP)

Text and language: spam filtering, sentiment classification, and text feature analysis.

Generative AI

Creating new content such as images; GANs are a classic generative approach.

Learning reflection

From algorithm names to problem-solving

Through this assignment, I gained a better understanding of how machine learning algorithms are grouped and used to solve real-world problems. Supervised learning uses labeled data to make predictions or classifications, while unsupervised learning identifies patterns and relationships without predefined labels.

Comparing algorithms helped me see that each has different strengths: Linear Regression predicts numerical values, K-Means groups similar data points, and CNNs are especially useful for image recognition. GANs can generate new content by training two neural networks against each other. Choosing an algorithm depends on the data, the problem, and the desired outcome; a method suited to tabular data may not be the best fit for computer vision or natural language processing.

Building this visual framework helped me organize the information and explain technical concepts more clearly. It also gave me a useful reference for future coursework and projects. Next, I would like to implement these algorithms with real datasets and compare their performance as I continue developing my skills in artificial intelligence and data science.
